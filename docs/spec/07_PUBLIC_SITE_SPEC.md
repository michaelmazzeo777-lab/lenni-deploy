# Public Site Specification

## Brand

**Leonida Field Guide — GTA VI Fan Channel**

Subtitle:

> Official evidence. Practical guides. Real experiments. Zero fake leaks.

## Page types

### Home
- current official-status card;
- latest guides;
- latest evidence articles;
- Field Lab results;
- corrections/update notices;
- channel links;
- newsletter placeholder.

### Official Facts hub
- release status;
- platforms;
- editions;
- current-as-of date;
- source references;
- explicit “not confirmed” section.

### Guide
- direct answer;
- platform/version/test date;
- spoiler level;
- steps;
- evidence/test method;
- update history;
- related guides.

### Evidence article
- source boundary;
- classification key;
- confirmed facts;
- observations;
- analysis;
- predictions;
- rumors or unverified items, when editorially necessary;
- limitations.

### Experiment
- question;
- setup;
- platform/version/date;
- controls;
- sample size;
- results;
- interpretation;
- limitations;
- retest trigger.

### Correction
- affected page;
- original statement;
- correction;
- reason;
- date;
- source;
- revision link.

### Methodology
- source hierarchy;
- claim labels;
- no-leak policy;
- corrections policy;
- AI-assistance disclosure;
- independence statement.

## Article metadata

- title;
- summary;
- published date;
- updated date;
- last verified date;
- author/editor;
- pillar;
- spoiler level;
- platform;
- version;
- classification badges;
- sources;
- corrections;
- canonical URL.

## SEO requirements

- server-rendered or pre-rendered content;
- canonical URLs;
- unique title and description;
- sitemap and robots;
- Article/NewsArticle/HowTo structured data only when accurate;
- breadcrumb metadata;
- Open Graph image using original branding;
- clean URLs;
- related content;
- no keyword stuffing;
- no thin AI pages;
- no doorway pages;
- no mass-generated near-duplicates.

## Accessibility

- WCAG 2.2 AA target;
- keyboard operation;
- visible focus;
- semantic landmarks;
- sufficient contrast;
- scalable text;
- descriptive alt text;
- reduced-motion support;
- transcripts for embedded videos;
- labels not dependent on color alone.

## Performance

Target, then measure:

- strong Core Web Vitals;
- optimized images;
- minimal client JavaScript for article pages;
- cached public content;
- no third-party scripts in MVP;
- privacy-respecting analytics only after approval.
