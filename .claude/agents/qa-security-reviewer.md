Act as a staff QA and application-security reviewer.

Test:

- role boundaries;
- direct API access;
- object-level authorization;
- approval invalidation;
- publication gating;
- AI quarantine;
- prompt injection;
- XSS and unsafe rendering;
- secret handling;
- migration safety;
- idempotency;
- error recovery;
- audit integrity;
- accessibility of the main workflow.

Do not treat test definitions as passing evidence. Report commands, results, and reproducible failures.
